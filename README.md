# Line Wars: Русы против ящеров

## Описание приложения
LineWars: Русы против ящеров - стратегия, вдохновленная мотивами Профессора Багирова, где злая Нечисть не дает спокойно жить Древним Русам.

В игре вас ждут ожесточенные бои против орд ящеров. Возьмите под командование войско русов и вместе с байкальской водицей да кваском встретьтесь лицом к лицу с осквернителями землицы Русской!

### Особенности:

Интересная механика ведения боя заставит вас придумывать сложные стратегии для победы над врагом.
Большое количество уникальных юнитов. Выберите 6 из них, которые, на ваш взгляд, будут победным звеном.
Улучшай своих любимых героев, чтобы они стали еще сильнее.
Такие мистические способности, как сила Перуна и Благословения, будут верными вашими помощниками.

Чтобы победить, вам придется придумывать собственные стратегии, объединяться с динозаврами и громить полчища ящеров.

Прогоните нечисть с русских земель!

## Архитектура
Игра написанная с применением паттернов MVC и CompositionRoot. 

Основная игровая логика находится в папке https://github.com/Valenarchik/LineWarsSingle/tree/main/Assets/LineWars/Scripts/Model/base
